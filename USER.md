# 📖 ForecastOS — End-User Guide & Platform Manual

Welcome to **ForecastOS**! ForecastOS is an enterprise-grade AI forecasting platform, decision engine, and cryptographic audit infrastructure powered by **Google's TimesFM 2.5** pretrained time-series foundation model.

This guide provides step-by-step instructions on how to use the dashboard, upload datasets, execute time-series predictions, interact with the **WebChat AI Assistant**, interpret AI decision recommendations, and verify on-chain smart contract audit proofs.

## 3. Uploading & Managing Datasets

### Supported Formats
* **CSV (`.csv`)** or **JSON (`.json`)** files.

### Column Requirements
Your file should contain at least two columns:
1. **Timestamp Column**: Named `timestamp`, `date`, or similar. Must be ISO 8601 formatted date strings (e.g. `2026-01-01`).
2. **Value Column**: Named `value`, `sales`, `price`, or similar numeric series.

### How to Upload:
1. Navigate to the **Datasets** tab.
2. Drag and drop your file into the dashed **Upload Zone** or click **Browse File**.
3. ForecastOS will automatically validate your file, clean missing values using linear interpolation, detect the frequency (Daily, Hourly, Monthly), and compute a unique SHA256 dataset fingerprint.

## 4. Generating Time-Series Forecasts

### Method A: Quick Demo Sample
Click the **"Load Sales Sample"** button in the top-right header to instantly run a 30-day forecast on synthetic retail sales data.

### Method B: Natural Language Instruction
Type your instruction directly into the top query bar or WebChat assistant:
> *"Forecast the next 30 days of sales"*  
> *"What happens if demand drops by 15%?"*

### Understanding Forecast Outputs:
* **Point Forecast ($q_{50}$ / Median)**: The expected central trajectory predicted by Google TimesFM 2.5.
* **60% Prediction Interval ($q_{20} - q_{80}$)**: The inner probability channel.
* **80% Prediction Interval ($q_{10} - q_{90}$)**: The outer uncertainty channel. As the forecast horizon extends further into the future, this band naturally widens.

## 5. Using the WebChat AI Assistant

ForecastOS includes **WebChat** — a floating AI assistant widget located in the bottom-right corner of the dashboard.

### How to Interact:
1. Click the glowing floating chat icon in the bottom-right corner to expand WebChat.
2. Type any query or click one of the **Quick Action Chips**:
   - 📈 **"Forecast 30 Days"**: Triggers a 30-day TimesFM prediction.
   - 🔍 **"Check Anomalies"**: Scans your data for historical Z-score outliers and prediction interval breaches.
   - 🛡️ **"Verify Contract"**: Queries the deployed `ForecastAuditRegistry.sol` smart contract ABI and address.
3. WebChat will reply with formatted text, risk scores, and automatically update your dashboard charts and tables in real time!

## 6. Two-Phase Anomaly Detection

ForecastOS uses a two-phase anomaly detection method to protect business operations:

1. **Context Phase (Historical Data)**:
   - Fits a linear trend on historical context.
   - Flags **WARNING** if $|Z| \ge 1.8$ and **CRITICAL** if $|Z| \ge 2.5$.
2. **Forecast Phase (Future Projections)**:
   - Compares incoming test/future observations against quantile prediction bands.
   - Flags **WARNING** if outside the 60% PI ($q_{20} - q_{80}$) and **CRITICAL** if outside the 80% PI ($q_{10} - q_{90}$).

## 7. Interpreting AI Decision Insights

Instead of leaving you with raw numbers, the AI Decision Agent synthesizes forecasts, confidence scores, and anomaly counts into clear business instructions:

* **Low Risk**: Model confidence is high and trend is stable. Recommends standard operations.
* **Medium / High Risk**: High volatility or anomaly spikes detected. Recommends:
  - *Sales*: "Increase inventory safety stock by 10-15% to meet projected demand growth."
  - *Crypto / Market*: "High volatility detected in quantile spread. Set strict stop-loss boundaries."
  - *Energy*: "Prepare peak load generation assets for increased grid consumption."

## 8. Cryptographic Blockchain Verification

ForecastOS guarantees auditability by computing four deterministic **SHA256** hashes for every forecast run:

```text
[Dataset Hash] + [Model Config Hash] + [Forecast Result Hash] ➔ [Composite Audit Hash]
```

### Verifying Proofs & Smart Contracts:
1. Navigate to the **Blockchain Audit** tab.
2. View the master composite hash and transaction receipt.
3. Click **"Verify Hashes"** — ForecastOS re-computes the hashes and verifies them against the anchored on-chain registry.
4. **Smart Contract ABI Viewer**: View the contract address (`0x99a5e0195a92d7ae0730226ded132d5e58676050`) and click **"Copy JSON ABI"** to copy the smart contract interface for integration into external Web3 dApps.

## 9. REST API Cheat Sheet

### Run Forecast
```bash
curl -X POST "http://localhost:8000/api/v1/forecast" \
     -H "Content-Type: application/json" \
     -d '{
       "series": [100, 105, 110, 115, 120],
       "horizon": 30,
       "frequency": "D"
     }'
```

### WebChat Message
```bash
curl -X POST "http://localhost:8000/api/v1/chat" \
     -H "Content-Type: application/json" \
     -d '{
       "message": "Forecast the next 30 days of sales"
     }'
```

### Fetch Smart Contract Info & ABI
```bash
curl -X GET "http://localhost:8000/api/v1/blockchain/contract-info"
```
